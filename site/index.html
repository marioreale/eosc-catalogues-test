What each card shows

Configuration

The checks of the test suite, evaluated for this entry: required fields, known node, protocol matching the type, HTTPS endpoint, OAI-PMH base URL without ?verb=, endpoint taken from the production sheet (for Poland, the Resource Hub record named). No network involved.

Availability probe

One request per endpoint during the run: GET the services endpoint (must answer 200 with JSON) or ?verb=Identify on the OAI-PMH base URL (must answer 200 with an Identify response).

Source

Every endpoint but Poland's comes from the production sheet (production_env_node_services.xlsx, October 2026). Poland's three catalogues, which the sheet does not list, come from the EOSC EU Node Resource Hub.

Not tested: compliance with the EEN services API or the OpenAIRE guidelines, harvesting of records, and metadata quality (DCAT/DCAT-AP). A green probe only means the endpoint is up and speaks the expected format.
